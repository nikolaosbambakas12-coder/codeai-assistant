# CodeAI — Coding Assistant

AI coding assistant powered by Google Gemini 2.0 Flash.

## Features
- Sign in / Register
- Persistent chat history per user
- Multiple chats with sidebar
- Focused on coding (Python, JS, Lua/Luau and more)
- Syntax highlighting for code blocks

## Setup
1. Open index.html in browser
2. Register an account
3. Click ⚙ Key and enter your Gemini API key
4. Start coding!
